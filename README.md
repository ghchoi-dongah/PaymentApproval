# 지불승인서 자동서식 (정적 HTML/CSS/JS 버전)

서버(백엔드) 없이 브라우저에서만 동작하는 순수 정적 웹페이지입니다.
GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 구조

```
payment-approval-static/
├─ index.html          # 전체 화면 (좌측 메뉴 + 지불승인서)
├─ css/style.css        # 스타일
├─ js/
│  ├─ constants.js      # 계정과목/항목/부서/구분 기준 데이터
│  ├─ app.js            # 표 계산, 회계전표, 엑셀 다운로드 로직
│  └─ vendor/
│     └─ xlsx.full.min.js  # 엑셀(.xlsx) 생성 라이브러리(SheetJS, MIT 라이선스)
└─ README.md
```

서버 코드가 전혀 없고, 브라우저에서 파일을 직접 열어도(`index.html` 더블클릭)
동작합니다. 엑셀 다운로드도 `js/vendor/xlsx.full.min.js`(SheetJS)를 이용해
브라우저 안에서 직접 파일을 만들어 내려받는 방식이라 별도 서버가 필요 없습니다.

## GitHub Pages로 올리는 방법

1. 이 폴더(`payment-approval-static`)의 내용을 새 GitHub 저장소의 **루트**에 그대로 올립니다.
   (예: 저장소 이름 `payment-approval`이면 `index.html`이 저장소 최상위에 있어야 합니다.)
2. GitHub 저장소 → **Settings → Pages** 로 이동합니다.
3. **Build and deployment** 에서 Source를 `Deploy from a branch`로 선택하고,
   Branch를 `main`(또는 사용 중인 브랜치), 폴더를 `/ (root)`로 선택 후 저장합니다.
4. 잠시 후 안내되는 주소(`https://<계정명>.github.io/<저장소명>/`)로 접속하면 됩니다.

명령줄로 올리는 예시:

```bash
cd payment-approval-static
git init
git add .
git commit -m "지불승인서 자동서식 정적 페이지"
git branch -M main
git remote add origin <저장소 URL>
git push -u origin main
```

## 화면 기능 (Spring Boot 버전과 동일)

- 상단 햄버거(☰) 버튼으로 좌측 메뉴를 열고 닫을 수 있습니다.
- 지출내역서 표: NO./지출일/계정과목/항목/상세내역/금액, 마지막 행에 합계(KRW) 표시,
  행 추가/삭제 버튼(최소 1개 행 유지), 계정과목 선택 후에만 항목 선택 가능.
- 지출일은 달력에서 선택하면 "2026-08-13" 형식으로 저장됩니다.
- 계정과목별 금액 / 항목별 금액 표가 자동 계산됩니다.
- 회계전표: 구분(법인/개인), 부서(미래에너지사업부/개발팀/영업지원팀) 선택에 따라
  - 차변 과목명: 부서가 "영업지원팀"이면 "판매비와관리비", 그 외에는 "개발투자비"
  - 대변 거래처: 구분이 "법인"이면 "하나비자(카드뒷자리4개)", "개인"이면 "사원"
  이 자동으로 반영되고, 계정과목별 차변 금액이 자동 합산됩니다.
- `⬇ 엑셀 다운로드` 버튼으로 화면에 보이는 모든 표(지출내역서 + 계정과목별/항목별
  금액 + 회계전표)를 하나의 .xlsx 파일로 내려받을 수 있습니다.

## 기준 데이터 수정 방법

계정과목/항목/부서 목록, "개발투자비 ↔ 판매비와관리비", "하나비자 ↔ 사원" 같은
규칙은 모두 `js/constants.js`와 `js/app.js` 상단에 모여 있습니다. 예를 들어
항목 목록을 바꾸고 싶다면 `js/constants.js`의 `accountItems` 객체만 수정하면
화면과 엑셀 다운로드 모두에 자동 반영됩니다.

## 확인해 주세요

차량유지비 항목 중 "추자권"은 원본 엑셀의 `계정과목` 시트 표기(주차권)와 비교해
오탈자로 보여 "주차권"으로 반영했습니다. 다른 표기를 원하시면 말씀해 주세요.

## 테스트

실제 Chromium 브라우저(Playwright)로 다음을 확인했습니다.
- 햄버거 메뉴 열기/닫기
- 행 추가/삭제 및 최소 1행 유지(안내 메시지 확인)
- 계정과목 → 항목 종속 선택
- 계정과목별/항목별 금액 자동 합산
- 회계전표: 부서를 "영업지원팀"으로 바꾸면 "판매비와관리비"로, 구분을 "개인"으로
  바꾸면 "사원"으로 자동 전환
- 엑셀 다운로드 후 생성된 .xlsx 파일을 열어 지출내역서/계정과목별·항목별 금액/
  회계전표 내용과 병합 셀, 통화 서식(₩#,##0)이 모두 올바르게 들어있는지 확인
